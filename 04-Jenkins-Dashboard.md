#  Jenkins Dashboard

## Objective
Explore the Jenkins UI and learn where to manage jobs and view results.

## Common areas
- **New Item:** Create a job or pipeline.
- **Build History:** Review previous executions.
- **Manage Jenkins:** Configure system settings and security.
- **Nodes:** Inspect configured build nodes.
- **Credentials:** Manage stored credentials, subject to permissions.
- **Console Output:** Read logs for an individual build.

Labels and layout may vary by Jenkins version and installed plugins.

## Lab
1. Sign in to Jenkins.
2. Find New Item and Manage Jenkins.
3. Locate build history after running a job.
4. Open a build's Console Output.

## Assignment
Describe how you would find the reason a build failed.
